# RESEARCH_TARGETS

Research public design principles from:
- Cold Clear / Cold Clear 2
- modern Guideline Tetris bots
- TETR.IO/Jstris multiplayer strategy
- SRS BFS / reachable move generation
- bitboard representations
- transposition tables
- beam search / iterative deepening
- evaluator features
- covered cells / cavities / wells
- downstack algorithms
- garbage-hole accessibility
- garbage cancellation
- B2B / combo efficiency
- T-spin / Spin search

Questions:
1. How do strong bots represent boards?
2. How do they generate only reachable placements?
3. Which features correlate with survival/downstack?
4. How do versus bots value cancellation vs outgoing attack?
5. How do they avoid destroying board quality for attack setup?
6. How do they control search time?
7. How are weights tuned?
8. What is realistic in browser JavaScript?

Use research to choose architecture; do not blindly copy code.
